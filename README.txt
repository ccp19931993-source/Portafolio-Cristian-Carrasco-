CRISTIAN CARRASCO — PORTFOLIO WEB
=================================

Versión final estática, bilingüe y responsive.

ABRIR EN LOCAL
1. Abre index.html en un navegador moderno.
2. Todas las imágenes, estilos y scripts están dentro de esta carpeta.

PUBLICAR
La carpeta se puede subir directamente a cualquier hosting estático (Netlify, Vercel, GitHub Pages o un hosting convencional). El archivo de entrada es index.html.

ANTES DE PUBLICAR EN DOMINIO PROPIO
- Sustituir/añadir una URL canónica cuando exista dominio definitivo.
- Si se desea, cambiar la imagen de previsualización social (og:image).
- Mantener toda la carpeta assets junto al index.html.
